# 수학

## 현재 상태
- 현재 점수: 25/30
- 목표 점수: 28/30
- 선택과목: 확률과 통계 (미적분, 기하는 범위 아님 — 자세한 내용은 `out/노트/범위.md` 참고)

## 폴더 용도
- 이 폴더는 수학 과목의 시험 준비 자료를 관리합니다.
- 단원별 개념 요약본
- 오답 관리 (틀린 문제, 틀린 이유, 재풀이 기록)
- 취약 단원에 맞춘 연습 문제

## 폴더 구조
- `in/문제은행`: 아직 풀지 않은 수능 문제 파일 업로드
- `in/오답`: 오답 관련 파일 업로드
- `out/노트`: 개념 요약 노트
- `out/체크문제`: 취약 유형 체크문제

## 문제은행 DB
- `in/문제은행`에 새 파일이 올라오면 `문제은행` 에이전트를 호출해 `in/문제은행/db.md`에 파싱된 문제를 누적 기록합니다.
- DB는 추가만 하며, 원본 파일이 삭제되어도 DB에서 해당 내용을 지우지 않습니다.

## 오답 DB
- `in/오답`에 새 파일이 올라오면 `오답분석` 스킬을 실행해 `in/오답/db.md`에 오답을 누적 기록합니다.
- 오답 원인(계산실수/문제오해/접근법몰라/시간부족)은 자동 판단하지 않고 사용자와 대화로 확인합니다.
- 이 DB도 append-only이며, 항목번호는 DB 전체에서 이어지는 일련번호입니다.

## 요약본(공식집)
- `요약본작성` 에이전트가 `out/노트/공식집.md`를 관리합니다. 파일은 하나만 유지되며, 실행할 때마다 새로 만들지 않고 기존 내용을 읽어 새 지식으로 개선합니다.
- 출제범위 전체 공식집 + 문제은행 커버리지 + 오답 인사이트/학습방안을 포함합니다.

## 체크문제
- `체크문제생성` 스킬이 `공식집.md`와 `문제은행/db.md`를 활용해 최고난도 융합형 응용문제를 만듭니다.
- 실행 시작 시 몇 문제를 만들지 먼저 물어보고, `out/체크문제`에 `체크문제_YYYYMMDD_HHMMSS_문제.md` / `체크문제_YYYYMMDD_HHMMSS_정답.md` 파일 쌍으로 새로 생성합니다(문제/정답 파일 분리, 여러 문제여도 한 쌍에 모두 포함).
