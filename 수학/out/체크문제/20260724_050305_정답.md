## 해설

### 1단계 — f(x)의 그래프 개형 파악 (수학Ⅱ, 미분: 삼차함수의 증가·감소와 극값)

$f(x) = x^3 - 6x^2 + 9x = x(x-3)^2$

$f'(x) = 3x^2 - 12x + 9 = 3(x-1)(x-3)$

- $x<1$: $f'(x)>0$ → 증가
- $1<x<3$: $f'(x)<0$ → 감소
- $x>3$: $f'(x)>0$ → 증가

극댓값 $f(1) = 1-6+9 = 4$, 극솟값 $f(3) = 27-54+27 = 0$, 그리고 $f(0)=0$.

즉 $f$는 $(-\infty,1)$에서 $(-\infty,4)$를 한 번씩, $(1,3)$에서 $(0,4)$를 한 번씩(역방향), $(3,\infty)$에서 $(0,\infty)$를 한 번씩 지나가는 전형적인 삼차함수 개형이다. 이 개형을 알아야 뒤의 $f(x)=k$ 형태 방정식의 실근 개수와 위치(2보다 큰지 작은지)를 정확히 판정할 수 있다.

### 2단계 — 수열의 규칙을 거꾸로 추적 (수학Ⅰ, 수열: 귀납적 정의)

규칙은 두 갈래다.
- $a_n < 2$이면 $a_{n+1}=f(a_n)$
- $a_n \ge 2$이면 $a_{n+1}=a_n-4$

**(1) $a_3=0$이 되는 $a_2$ 구하기**

- $a_2 \ge 2$인 경우: $a_2 - 4 = 0 \Rightarrow a_2 = 4$ (조건 $\ge 2$ 만족 ✓)
- $a_2 < 2$인 경우: $f(a_2) = 0 \Rightarrow x(x-3)^2 = 0 \Rightarrow x=0$ 또는 $x=3$(중근). 이 중 $2$보다 작은 것은 $x=0$뿐이므로 $a_2 = 0$.

따라서 $a_2 \in \{0, 4\}$.

**(2) 각 $a_2$에 대해 $a_1$ 구하기**

① $a_2 = 4$인 경우
- $a_1 \ge 2$: $a_1 - 4 = 4 \Rightarrow a_1 = 8$ (조건 ✓)
- $a_1 < 2$: $f(a_1) = 4 \Rightarrow x^3-6x^2+9x-4=0 \Rightarrow (x-1)^2(x-4)=0 \Rightarrow x=1$(중근) 또는 $x=4$. 이 중 $2$보다 작은 것은 $x=1$뿐이므로 $a_1 = 1$.

② $a_2 = 0$인 경우
- $a_1 \ge 2$: $a_1 - 4 = 0 \Rightarrow a_1 = 4$ (조건 ✓)
- $a_1 < 2$: $f(a_1) = 0 \Rightarrow x(x-3)^2=0 \Rightarrow x=0$ 또는 $x=3$(중근). 이 중 $2$보다 작은 것은 $x=0$뿐이므로 $a_1 = 0$.

따라서 조건을 만족하는 $a_1$의 값은 $\{0, 1, 4, 8\}$.

### 3단계 — 검산 (정방향 대입)

- $a_1=1$: $1<2 \Rightarrow a_2=f(1)=4$; $4\ge2 \Rightarrow a_3=4-4=0$ ✓
- $a_1=8$: $8\ge2 \Rightarrow a_2=8-4=4$; $4\ge2 \Rightarrow a_3=4-4=0$ ✓
- $a_1=0$: $0<2 \Rightarrow a_2=f(0)=0$; $0<2 \Rightarrow a_3=f(0)=0$ ✓
- $a_1=4$: $4\ge2 \Rightarrow a_2=4-4=0$; $0<2 \Rightarrow a_3=f(0)=0$ ✓

네 값 모두 성립을 확인했다.

### 4단계 — 답

$$0+1+4+8 = 13$$

## 이 문제를 만든 이유

`out/노트/공식집.md`의 "오답 인사이트" 섹션은 아직 `in/오답/db.md`가 없어 실제 오답 데이터를 기반으로 취약 단원을 지목할 수 없는 상태다(스킬 규칙 2에 따라, 오답 데이터가 없을 때는 공식집·문제은행에서 난이도가 높거나 신뢰도가 낮다고 표시된 영역을 대신 겨냥한다).

이번 문제는 공식집 3장 "단원별 취약점"에 3개년 모두 최고난도 자리를 반복 차지한다고 명시된 두 유형을 동시에 겨냥했다.

1. **수학Ⅱ 미분 — 구간별/삼차함수 그래프 개형 추론** (`#14, #22, #67*, #107*` — 이 중 `#67`, `#107`은 공식집에 저신뢰도(`*`)로 표시된 항목). 특히 `#107`(구간별 정의된 함수의 미분가능성·극값 개수 추론)의 "그래프 개형을 표로 정리해 조건을 역으로 추적한다"는 발상을 가져와, 이번 문제에서는 $f(x)=k$ 방정식의 실근을 극값(4, 0)과 비교해 2보다 크고 작음을 판정하는 형태로 변형했다.
2. **수학Ⅰ 수열 — 귀납적으로 정의된 수열에서 조건을 만족하는 모든 첫째항 찾기** (`#15, #66, #110, #114`). `#66`(구간·case를 나눠 빈칸을 채우는 방식)과 `#62`(가장 단순한 $a_{n+1}=f(a_n)$ 꼴)의 발상을 결합해, 이번 문제는 조건에 따라 두 개의 서로 다른 점화식으로 갈라지는(분기형) 구조를 만들고, 마지막 항에서 거꾸로($a_3 \to a_2 \to a_1$) 모든 가능한 첫째항을 찾도록 설계했다. 각 역추적 단계마다 두 갈래(부등식 조건 충족 여부)를 모두 검토해야 하고, 삼차방정식을 두 번 인수분해해야 하므로 계산량과 논리적 케이스 관리 부담이 모두 크다.

두 단원을 그대로 이어붙인 것이 아니라, 미분(1단계: 그래프 개형 파악)이 수열의 역추적(2단계: 케이스 분기)에서 방정식의 실근 개수와 위치를 판정하는 데 필수적으로 쓰이도록 설계해, 단순 결합이 아닌 진짜 융합형 문제가 되도록 했다. 문제은행의 `#60, #61`(확인필요 표시된 다른 저신뢰도 항목)은 이번엔 소재로 직접 쓰지 않았으나, 다음 체크문제에서는 확률과 통계 쪽(`#28, #70, #74` 조건부확률 / `#30, #75, #121` 정규분포)이나 적분(`#61` 정적분으로 정의된 함수의 극값) 계열도 순환적으로 다뤄볼 필요가 있다.
