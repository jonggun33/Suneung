## 1. 단원별 공식집

### 1-1. 수학Ⅰ — 지수와 로그
- **지수법칙**: a>0, m,n이 실수일 때 a^m·a^n=a^(m+n), (a^m)^n=a^(mn), a^m/a^n=a^(m-n). 거듭제곱근의 정의(ⁿ√a)와 유리수 지수로의 변환이 계산 문제의 출발점. (관련 문제: #1, #47, #93)
- **로그의 정의와 성질**: log_a N = x ⟺ a^x = N (a>0, a≠1, N>0). log_a MN=log_a M+log_a N, log_a(M/N)=log_a M-log_a N, log_a M^k = k log_a M, 밑변환공식 log_a b = log_c b/log_c a. (관련 문제: #52, #100)
- **지수방정식·부등식**: 밑을 통일하거나 치환(t=a^x)해서 이차방정식/부등식으로 변환. (관련 문제: #16)
- **로그방정식·부등식**: 진수조건(진수>0, 밑>0·밑≠1)을 먼저 확인한 뒤 밑 통일. (관련 문제: #108)
- **지수함수·로그함수의 그래프**: y=a^x와 y=log_a x는 직선 y=x에 대해 대칭(서로 역함수). 점근선(지수함수는 x축, 로그함수는 y축), a>1이면 증가, 0<a<1이면 감소. 그래프 위 점, 접선의 기울기, 넓이 등과 결합되는 고난도 문항 다수. (관련 문제: #56, #68, #112)
- **수직선 위 점의 내분점(로그 좌표 활용)**: 두 점 P(a), Q(b)를 m:(1-m)으로 내분하는 점의 좌표 = (1-m)a+mb. 로그값을 좌표로 놓고 내분점 조건을 세우는 융합 유형. (관련 문제: #9)

### 1-2. 수학Ⅰ — 삼각함수
- **호도법과 일반각**: 180°=π(rad). 동경이 나타내는 일반각 2nπ+θ.
- **삼각함수의 정의(단위원)**: sinθ=y, cosθ=x, tanθ=y/x. 사분면별 부호 판정이 필수.
- **삼각함수 사이의 관계**: sin²θ+cos²θ=1, tanθ=sinθ/cosθ, 1+tan²θ=1/cos²θ.
- **유도공식(환원공식)**: sin(-θ)=-sinθ, cos(-θ)=cosθ, sin(π/2±θ)=cosθ류, cos(π-θ)=-cosθ 등. 부호가 잘 틀리는 부분이므로 단위원 그림으로 매번 확인. (관련 문제: #3, #98)
- **삼각함수의 그래프**: y=a sin(bx+c)+d 꼴의 주기 2π/|b|, 최댓값 a+d·최솟값 -a+d(a>0). 최댓값 조건에서 위상·주기 동시 결정하는 유형 빈출. (관련 문제: #54, #102)
- **삼각방정식·부등식**: 그래프 또는 단위원을 이용해 해의 개수·범위를 구함. 주기성을 이용해 정의역을 좁혀 풀이. (관련 문제: #19)
- **사인법칙**: a/sinA=b/sinB=c/sinC=2R (R: 외접원 반지름).
- **코사인법칙**: a²=b²+c²-2bc cosA.
- **삼각형의 넓이**: S=(1/2)ab sinC. 사각형은 두 삼각형으로 쪼개 사인법칙·코사인법칙·넓이비를 함께 사용하는 고난도 융합 문항으로 자주 출제. (관련 문제: #13, #60*, #64, #106)

### 1-3. 수학Ⅰ — 수열
- **등차수열**: 일반항 a_n=a_1+(n-1)d, 합 S_n=n(a_1+a_n)/2=n{2a_1+(n-1)d}/2. (관련 문제: #104)
- **등비수열**: 일반항 a_n=a_1·r^(n-1), 합 S_n=a_1(r^n-1)/(r-1) (r≠1). S_n과 항 사이의 관계식(S_4-S_2=3a_4 형태)을 정리해 미지수를 구하는 유형이 자주 나옴. (관련 문제: #6, #58, #95)
- **시그마의 성질**: Σ(a_k±b_k)=Σa_k±Σb_k, Σc·a_k=c·Σa_k, Σ_{k=1}^n c = nc. 자연수의 거듭제곱 합 공식 Σk=n(n+1)/2, Σk²=n(n+1)(2n+1)/6도 알아둘 것. (관련 문제: #18, #49)
- **부분분수를 이용한 시그마**: 1/(a_k a_{k+1}) 꼴은 등차수열일 때 1/d·(1/a_k - 1/a_{k+1})로 분해해 상쇄합(telescoping)으로 계산. (관련 문제: #11)
- **수열의 귀납적 정의**: a_{n+1}=f(a_n) 꼴에서 규칙(주기성, 짝/홀 분기)을 찾아 역추적하는 유형. 조건을 만족하는 첫째항을 모두 찾는 문제가 고난도로 출제됨 — case를 그림/표로 정리하는 습관이 중요. (관련 문제: #15, #62, #66, #110, #114)

### 1-4. 수학Ⅱ — 함수의 극한과 연속
- **함수의 극한**: lim_{x→a} f(x) 값이 존재하려면 좌극한=우극한. 부정형(0/0, ∞/∞)은 인수분해·유리화로 처리.
- **함수의 연속**: f(x)가 x=a에서 연속 ⟺ lim_{x→a} f(x) = f(a) (극한값이 존재하고 함숫값과 같음). 구간별로 정의된 함수의 이음매에서 좌극한=우극한=함숫값 조건으로 미지수를 구하는 문제가 매 시험 1번대 필수 출제. (관련 문제: #4, #50, #96)
- **극한이 존재할 조건을 이용한 고난도 추론**: lim_{x→a} g(x)/h(x) 형태에서 분모가 0이 되는 점에서 분자도 0이어야 극한이 존재한다는 성질을 삼차함수 조건 추론에 활용. (관련 문제: #113)

### 1-5. 수학Ⅱ — 미분
- **미분계수의 정의**: f'(a) = lim_{h→0} (f(a+h)-f(a))/h. 순간변화율의 정의를 그대로 묻는 2점 문항이 매 시험 초반에 출제되므로 반드시 실수 없이 처리. (관련 문제: #2, #48, #94)
- **다항함수의 도함수**: (x^n)'=nx^(n-1), 곱의 미분법 (fg)'=f'g+fg'. (관련 문제: #17, #51, #97)
- **접선의 방정식**: 점 (a,f(a))에서의 접선 y=f'(a)(x-a)+f(a). 곡선 위 점에서의 접선 조건으로 미지수를 구하거나 두 접선이 이루는 도형의 넓이를 구하는 유형. (관련 문제: #20, #55)
- **함수의 증가·감소와 극대·극소**: f'(x)>0이면 증가, f'(x)<0이면 감소. f'(x)=0인 점에서 부호가 바뀌면 극값. 삼차함수의 그래프 개형(변곡점 대칭성 포함)을 암산으로 그릴 수 있어야 그래프 개수/교점 추론 문제를 빠르게 풂. (관련 문제: #5, #7, #111)
- **함수의 그래프 개형 추론(구간별 정의 함수)**: 실수 t에 대해 y=f(x)와 y=t의 교점 개수 g(t)를 분석하는 유형은 최근 21~22번 고난도 문항의 단골 소재. f(x)의 극값·불연속점·기울기 부호를 표로 정리해 g(t)의 값이 바뀌는 경계를 찾는 것이 핵심. (관련 문제: #14, #22, #67*, #107*)
- **함수의 최대·최소**: 닫힌구간에서 극값과 구간의 끝값을 비교. 매개변수 t에 대한 최댓값/최솟값 함수 g(t)를 새로 정의하는 유형이 어려움. (관련 문제: #21, #65)
- **속도와 가속도**: 위치 x(t)의 도함수가 속도 v(t)=x'(t), v(t)의 도함수가 가속도 a(t)=v'(t). 운동 방향이 바뀌는 시점은 v(t)=0에서 부호가 바뀌는 순간. (관련 문제: #57, #103)

### 1-6. 수학Ⅱ — 적분
- **부정적분**: ∫x^n dx = x^(n+1)/(n+1)+C (n≠-1). F'(x)=f(x)일 때 F(x)를 f(x)의 부정적분이라 함. F(0) 등 초기조건으로 적분상수 C를 결정. (관련 문제: #63, #109)
- **정적분의 정의와 미적분학의 기본정리**: d/dx ∫_a^x f(t)dt = f(x). ∫_0^x f(t)dt=g(x) 꼴로 주어진 식을 양변 미분해 f(x)를 구하는 유형. (관련 문제: #99)
- **정적분의 계산과 성질**: ∫_a^b f(x)dx = F(b)-F(a). 구간을 쪼개거나 우함수/기함수 성질을 활용해 계산량을 줄일 것. (관련 문제: #8, #101)
- **넓이**: 곡선과 x축 사이의 넓이 = ∫|f(x)|dx, 두 곡선 사이의 넓이 = ∫|f(x)-g(x)|dx. 접선·구간별 함수와 결합해 넓이의 최댓값을 구하는 문항, 두 접선과 좌표축으로 둘러싸인 넓이를 구하는 문항이 고난도로 출제. (관련 문제: #12, #53, #59, #105)
- **정적분으로 정의된 함수의 극값**: h(x)=∫_a^x f(t)dt 꼴에서 h'(x)=f(x)이므로, f(x)의 부호가 바뀌는 지점이 h(x)의 극값점. 구간별 함수 g(x)와 결합해 극값의 개수를 세는 유형. (관련 문제: #61*)
- **속도로부터 위치·이동거리 구하기**: 위치 변화량 = ∫_a^b v(t)dt, 이동거리 = ∫_a^b |v(t)|dt. (관련 문제: #10)

### 1-7. 확률과 통계 — 경우의 수
- **순열과 조합**: _nP_r = n!/(n-r)!, _nC_r = n!/(r!(n-r)!).
- **같은 것이 있는 순열**: n개 중 같은 것이 각각 p, q, r개(p+q+r=n)일 때 n!/(p!q!r!). (관련 문제: #23)
- **중복순열·중복조합**: 중복순열 _nΠ_r = n^r, 중복조합 _nH_r = _{n+r-1}C_r. (관련 문제: #69)
- **이항정리**: (a+b)^n = Σ_{k=0}^n _nC_k a^(n-k) b^k. 특정 항의 계수를 구할 때 일반항 _nC_k a^(n-k)b^k을 이용. (관련 문제: #115)
- **조건을 만족하는 경우의 수 세기**: 대소관계·부등식 조건이 있는 순서쌍이나 함수의 개수를 셀 때는 조건을 만족하는 구간을 나눠 곱의 법칙/합의 법칙을 적용. 최근 시험에서 4점 최고난도 문항으로 자주 등장. (관련 문제: #29, #76, #120)

### 1-8. 확률과 통계 — 확률
- **확률의 덧셈정리**: P(A∪B)=P(A)+P(B)-P(A∩B). (관련 문제: #71, #116)
- **여사건의 확률**: P(A^C)=1-P(A). "적어도 하나" 유형에 필수. (관련 문제: #118)
- **확률의 곱셈정리와 조건부확률**: P(B|A)=P(A∩B)/P(A), P(A∩B)=P(A)P(B|A). 표(또는 나무그림)로 전체 경우를 정리한 뒤 조건에 맞는 경우만 골라내는 것이 핵심. 최근 시험(2024, 2026)에서 확통 4점 문항의 대표 유형. (관련 문제: #28, #70, #74)
- **사건의 독립**: A, B가 독립 ⟺ P(A∩B)=P(A)P(B) ⟺ P(B|A)=P(B). 독립 조건과 여사건 확률을 함께 묻는 유형. (관련 문제: #24)
- **순열/조합을 활용한 확률 계산**: 확률 = (조건을 만족하는 경우의 수)/(전체 경우의 수). (관련 문제: #25)
- **반복시행의 확률**: n번의 독립시행에서 사건이 r번 일어날 확률 = _nC_r p^r (1-p)^(n-r). (관련 문제: #122)

### 1-9. 확률과 통계 — 통계
- **이산확률변수의 기댓값·분산·표준편차**: E(X)=Σx_i P(X=x_i), V(X)=E(X²)-{E(X)}², σ(X)=√V(X). E(aX+b)=aE(X)+b, V(aX+b)=a²V(X). (관련 문제: #26, #73, #119)
- **이항분포**: X~B(n,p)일 때 E(X)=np, V(X)=np(1-p). n이 충분히 크면 정규분포 N(np, np(1-p))로 근사(정규근사). (관련 문제: #75)
- **정규분포와 표준화**: X~N(m,σ²)일 때 Z=(X-m)/σ ~ N(0,1). 표준정규분포표의 P(0≤Z≤z) 값을 이용해 확률을 계산. (관련 문제: #30, #121)
- **모평균의 신뢰구간(추정)**: 모표준편차 σ, 표본크기 n, 표본평균 x̄일 때 신뢰도 (1-α)에 대한 신뢰구간은 x̄-z_α σ/√n ≤ m ≤ x̄+z_α σ/√n (z_α는 신뢰도에 대응하는 표준정규분포 값, 예: 95%→1.96, 99%→2.58). 신뢰구간의 길이 = 2z_α σ/√n. (관련 문제: #27, #72, #117)

## 3. 오답 인사이트 및 학습 방안

### 오답원인별 집계
- 아직 오답 데이터 없음 (`in/오답/db.md` 파일이 존재하지 않음). 오답 파일을 `in/오답`에 업로드하고 `오답분석` 스킬을 실행하면 이 섹션에 계산실수/문제오해/접근법몰라/시간부족 집계와 단원별 교차분석이 자동으로 채워진다.

### 단원별 취약점
- 오답 데이터가 쌓이기 전까지는 판단 보류. 다만 문제은행 DB의 4점 고난도 문항 분포를 참고하면, 아래 유형들이 3개년 모두에서 반복적으로 최고난도(20~22번, 29~30번) 자리를 차지하고 있어 사전 대비가 필요하다:
  - 수학Ⅱ 미분: 구간별로 정의된 삼차함수의 그래프 개형·교점 개수 추론 (#14, #22, #67, #107)
  - 수학Ⅱ 적분: 정적분으로 정의된 함수의 극값, 접선과 넓이의 혼합 (#12, #59, #61, #105)
  - 수학Ⅰ 수열: 귀납적으로 정의된 수열에서 조건을 만족하는 모든 첫째항 찾기 (#15, #66, #110, #114)
  - 확률과 통계: 조건부확률(반복시행) (#28, #70, #74), 정규분포·이항분포 근사 계산 (#30, #75, #121)

### 종합 추천 (오답 데이터 반영 전 잠정)
1. 오답 파일을 업로드해 `in/오답/db.md`를 생성하는 것이 최우선 — 실제 취약 단원과 오답 원인(계산실수 vs 접근법몰라 vs 시간부족)을 알아야 25→28점을 위한 학습 시간을 정확히 배분할 수 있다.
2. 목표 상승분(+3점)은 대개 20~22번, 29~30번급 4점 문항 1~2개를 추가로 맞히면 달성되므로, 위 "단원별 취약점"에 정리한 4대 고난도 유형(삼차함수 그래프 추론, 정적분으로 정의된 함수, 수열 귀납적 정의, 확통 조건부확률/정규분포)을 우선 순위로 반복 훈련할 것.
3. 미분계수의 정의(#2, #48, #94)처럼 쉬운 2점 문항은 실수를 줄이는 것이 최우선 — 오답 데이터가 쌓이면 이 영역에서 계산실수 비율이 높은지 확인해 검산 루틴 여부를 정할 것.
4. 확률과 통계는 표/나무그림으로 전체 경우의 수를 정리하는 습관이 조건부확률·반복시행 문제의 실수를 줄이는 핵심이므로, 체크문제 풀이 시 항상 표부터 그리는 루틴화가 필요.
5. 다음 요약본 갱신 시점: 오답 DB가 생기거나 새 문제은행 파일이 추가될 때마다 이 파일을 다시 실행해 누적 개선.
