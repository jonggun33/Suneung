## 1. 단원별 요약본

### 수학Ⅰ — 지수와 로그
- 지수법칙: $a^m \cdot a^n = a^{m+n}$, $(a^m)^n = a^{mn}$, $a^m/a^n = a^{m-n}$ (#1,#47,#93)
- 로그: $\log_a N = x \Leftrightarrow a^x = N$. $\log_a MN = \log_a M + \log_a N$, $\log_a M^k = k\log_a M$, 밑변환 $\log_a b = \log_c b / \log_c a$ (#52,#100)
- 지수/로그방정식·부등식: 밑 통일 또는 치환($t = a^x$), 로그는 진수조건 먼저 확인 (#16,#108)
- 지수함수·로그함수 그래프: $y=a^x$와 $y=\log_a x$는 $y=x$ 대칭, 점근선(x축/y축) (#56,#68,#112)
- 내분점: $(1-m)a+mb$ — 로그좌표 융합 유형 (#9)

### 수학Ⅰ — 삼각함수
- 호도법: $180° = \pi$. 단위원 정의: $\sin\theta=y$, $\cos\theta=x$, $\tan\theta=y/x$
- $\sin^2\theta+\cos^2\theta=1$, $\tan\theta=\sin\theta/\cos\theta$, $1+\tan^2\theta=1/\cos^2\theta$
- 유도공식: $\sin(-\theta)=-\sin\theta$, $\cos(\pi-\theta)=-\cos\theta$ 등 — 단위원으로 확인 (#3,#98)
- 그래프 $y=a\sin(bx+c)+d$: 주기 $2\pi/|b|$, 최댓값 $a+d$ (#54,#102)
- 삼각방정식: 그래프/단위원+주기성 (#19)
- 사인법칙 $a/\sin A = 2R$, 코사인법칙 $a^2=b^2+c^2-2bc\cos A$, 넓이 $S=\frac{1}{2}ab\sin C$ — 사각형 융합 고난도 (#13,#60*,#64,#106)

### 수학Ⅰ — 수열
- 등차: $a_n=a_1+(n-1)d$, $S_n=n(a_1+a_n)/2$ (#104)
- 등비: $a_n=a_1 r^{n-1}$, $S_n=a_1(r^n-1)/(r-1)$ — $S_n$ 관계식 유형 (#6,#58,#95)
- Σ 성질: $\Sigma(a_k \pm b_k)$, $\Sigma k=n(n+1)/2$, $\Sigma k^2=n(n+1)(2n+1)/6$ (#18,#49)
- 부분분수 telescoping: $\frac{1}{a_k a_{k+1}}=\frac{1}{d}\left(\frac{1}{a_k}-\frac{1}{a_{k+1}}\right)$ (#11)
- 귀납적 정의 $a_{n+1}=f(a_n)$: 주기/분기 역추적, 첫째항 전부 찾기 유형 고난도 (#15,#62,#66,#110,#114)

### 수학Ⅱ — 함수의 극한과 연속
- lim: 좌극한=우극한, 부정형은 인수분해/유리화
- 연속: $\lim_{x\to a} f(x) = f(a)$ — 구간별 함수 이음매 조건 매 시험 필수 (#4,#50,#96)
- 극한 존재 조건(분모 0→분자도 0) 활용한 삼차함수 추론 (#113)

### 수학Ⅱ — 미분
- $f'(a)=\lim_{h\to0}\dfrac{f(a+h)-f(a)}{h}$ (#2,#48,#94)
- $(x^n)'=nx^{n-1}$, $(fg)'=f'g+fg'$ (#17,#51,#97)
- 접선: $y=f'(a)(x-a)+f(a)$ (#20,#55)
- 증가/감소·극값: $f'(x)>0$ 증가, $f'(x)=0$ 부호변화 시 극값 — 삼차함수 개형 암산 필수 (#5,#7,#111)
- 구간별 함수 $y=f(x)$와 $y=t$ 교점개수 $g(t)$: 최근 21~22번 단골, 극값·불연속점 표로 정리 (#14,#22,#67*,#107*)
- 최대·최소: 극값 vs 구간 끝값, $g(t)$ 정의 유형 (#21,#65)
- 속도/가속도: $v=x'$, $a=v'$, 방향전환은 $v=0$ 부호변화 (#57,#103)

### 수학Ⅱ — 적분
- $\int x^n dx = \dfrac{x^{n+1}}{n+1}+C$ (#63,#109)
- $\dfrac{d}{dx}\displaystyle\int_a^x f(t)dt=f(x)$ — 양변미분 유형 (#99)
- $\displaystyle\int_a^b f(x)dx=F(b)-F(a)$, 우함수/기함수 활용 (#8,#101)
- 넓이 $\int|f(x)-g(x)|dx$ — 접선·구간별함수 결합 고난도 (#12,#53,#59,#105)
- $h(x)=\displaystyle\int_a^x f(t)dt$의 극값: $h'(x)=f(x)$ 부호전환점 (#61*)
- 위치변화량 $\int v\,dt$, 이동거리 $\int|v|\,dt$ (#10)

### 확률과 통계 — 경우의 수
- ${}_nP_r=n!/(n-r)!$, ${}_nC_r=n!/(r!(n-r)!)$
- 같은 것이 있는 순열: $n!/(p!q!r!)$ (#23)
- 중복순열 $n^r$, 중복조합 ${}_{n+r-1}C_r$ (#69)
- 이항정리: $(a+b)^n=\Sigma\, {}_nC_k\, a^{n-k}b^k$ (#115)
- 조건부 경우의 수(대소관계 등): 구간 나눠 곱/합의 법칙 — 4점 최고난도 단골 (#29,#76,#120)

### 확률과 통계 — 확률
- $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ (#71,#116)
- 여사건 $P(A^C)=1-P(A)$ — "적어도 하나" (#118)
- 조건부확률 $P(B|A)=P(A\cap B)/P(A)$ — 표/나무그림 필수, 확통 4점 대표유형 (#28,#70,#74)
- 독립: $P(A\cap B)=P(A)P(B) \Leftrightarrow P(B|A)=P(B)$ (#24)
- 확률=경우의 수/전체 경우의 수 (#25)
- 반복시행: ${}_nC_r\, p^r(1-p)^{n-r}$ (#122)

### 확률과 통계 — 통계
- $E(X)=\Sigma x_i P(X=x_i)$, $V(X)=E(X^2)-\{E(X)\}^2$, $E(aX+b)=aE(X)+b$, $V(aX+b)=a^2V(X)$ (#26,#73,#119)
- 이항분포 $B(n,p)$: $E=np$, $V=np(1-p)$, 정규근사 (#75)
- 정규분포: $Z=(X-m)/\sigma \sim N(0,1)$, 표준정규분포표 활용 (#30,#121)
- 신뢰구간: $\bar{x} \pm z_\alpha \cdot \sigma/\sqrt{n}$ (95%→1.96, 99%→2.58) (#27,#72,#117)
