You build and maintain an append-only markdown database file from raw files uploaded into a source folder. You will be told:

- `source_folder`: where new files (수능 문제, 오답 등) get dropped
- `db_file`: the markdown file that accumulates parsed entries (create it if missing)

## Rules

1. **Append-only.** Never delete, rewrite, or reorder existing sections in `db_file`. If a source file is later removed from `source_folder`, its section in `db_file` stays untouched.
2. **Only process new files.** A file is "new" if there is no `## 출처: <파일명>` section for it already in `db_file`.
3. **Never re-derive already-processed content.** Skip any file already represented, even if its content has changed — flag that case in your summary instead of re-parsing it.

## Steps

1. If `db_file` doesn't exist, create it with a top-level `# {폴더명} DB` header.
2. Read `db_file` and collect every filename listed in a `## 출처: <파일명>` heading — this is the processed set.
3. List all files in `source_folder` (skip hidden files and `db_file` itself if it lives inside that folder).
4. Compute `new_files` = files in `source_folder` not in the processed set. If empty, report "새 파일 없음" and stop — do not touch `db_file`.
5. For each new file, sorted by filename:
   - Read its full content (text, PDF, or image as needed).
   - Extract individual items relevant to the folder's purpose:
     - **문제은행류 폴더**: each 문제 → **항목번호(필수), 시험이름(필수)**, 문제 지문/본문, 보기/선택지, **정답(필수, 가능하면)**, **정답출처(필수)**, 유형(추정 가능하면)
       - `항목번호`: DB 전체를 관통하는 일련번호. 파일이 바뀌어도 리셋되지 않고 이어서 증가한다. 새로 추가하기 전에 `db_file`에서 마지막으로 쓰인 항목번호를 찾아 그다음 번호부터 부여한다 (DB가 비어 있으면 1부터).
       - `시험이름`: 문제가 출제된 시험명 (예: "2025학년도 대학수학능력시험", "2024년 6월 모의평가"). 파일명이나 본문에서 추론한다. 어디서도 확인할 수 없으면 빈 값으로 두지 말고 `시험이름: 확인필요`로 표시하고 요약 보고에 flag한다.
       - `정답`: 원본 파일에 정답표가 있으면 그대로 사용한다. 정답표가 없으면 문제를 직접 풀어서 정답을 결정한다. 직접 풀어도 확신이 낮으면 빈 값 대신 `정답: 확인필요`로 표시하고 요약 보고에 flag한다.
       - `정답출처`: `공식`(원본 파일의 정답표 기반) 또는 `AI풀이`(에이전트가 직접 계산해서 도출) 중 하나. 신뢰도 구분을 위해 반드시 기록한다.
     - 오답류 폴더: each 오답 항목 → 문제, 학생이 고른 답, 정답, 틀린 이유(파일에 있으면)
   - Append one section to `db_file`:
     ```
     ## 출처: {파일명}
     _추가일: {오늘 날짜, YYYY-MM-DD}_

     ### 항목번호: {n}
     - 시험이름: ...
     - 문제: ...
     - 보기: ...
     - 정답: ...
     - 정답출처: {공식|AI풀이}
     ```
   - Use `Edit` to append at the end of the file rather than rewriting the whole file.
6. Report a short summary: how many files were newly added, how many items were extracted per file, and any files skipped with a reason (e.g. unreadable, already processed but changed).
