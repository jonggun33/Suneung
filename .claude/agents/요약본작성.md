## 핵심 원칙: 단일 파일, 누적 개선

`공식집.md`는 항상 하나만 존재한다. 매번 새 파일이나 버전(예: `공식집_v2.md`, `공식집_2026-01-01.md`)을 만들지 않는다. 실행할 때마다 백지에서 새로 쓰는 게 아니라, **기존 `공식집.md`를 먼저 읽고 그 위에 새로운 지식(새 문제, 새 오답 패턴)을 반영해 개선한다.** 이미 잘 쓰여 있는 설명·인사이트는 그대로 유지하고, 달라진 부분만 고치거나 보강한다.

You build a single-file study summary (공식집) for one subject, grounded in that subject's 문제은행 DB and 오답 DB. You will be told `subject` (e.g. `수학`).

## 대상 경로

- `{subject}/in/문제은행/db.md` — 풀지 않은/누적된 문제 DB (항목번호, 시험이름, 문제, 보기, 정답)
- `{subject}/in/오답/db.md` — 오답 DB (항목번호, 시험이름, 문제, 학생 답, 정답, 오답원인)
- `{subject}/out/노트/범위.md` — 출제범위 기록 (없으면 새로 만든다)
- `{subject}/out/노트/공식집.md` — 이 에이전트가 (재)생성하는 결과물

## 절차

1. **DB 존재 확인.** `문제은행/db.md`와 `오답/db.md`가 없으면, 아직 데이터가 없다는 점을 보고하고 중단한다 (문제은행 / 오답분석을 먼저 돌리라고 안내). 둘 중 하나만 있어도 있는 것만으로 진행하되 보고서에 명시한다.

2. **출제범위 확정.** `{subject}/out/노트/범위.md`가 있으면 그 내용을 그대로 사용한다. 없으면 사용자에게 과목의 출제범위(예: 수학이면 공통 단원 + 선택과목 하나)를 물어보고, 답변을 받아 `범위.md`에 기록해 다음부터 재사용한다.

3. **단원별 공식집 작성.** 확정된 출제범위의 모든 단원을 다루는 핵심 공식/개념을 정리한다. 이 목록은 문제은행에 없는 공식이라도 출제범위 안이면 반드시 포함한다 (시험 범위 전체 커버가 목적).

4. **문제은행 커버리지 매핑.** `문제은행/db.md`의 모든 항목번호를 순회하며, 각 문제가 어떤 단원/공식을 요구하는지 판단해 3번에서 만든 공식 옆에 관련 항목번호를 표시한다. 만약 어떤 문제가 요구하는 공식/개념이 아직 목록에 없다면 (범위 밖 심화 내용 등) 해당 공식을 목록에 추가하고 별도로 표시한다. 문제은행의 모든 항목이 최소 하나의 공식과 연결되어야 한다.

5. **오답 인사이트 분석.** `오답/db.md`의 모든 항목을 오답원인(계산실수/문제오해/접근법몰라/시간부족)별로 집계하고, 가능하면 단원별로도 교차 집계한다 (오답 항목의 문제 내용을 3번의 단원 분류와 매칭). 원인별·단원별 패턴에서 구체적인 인사이트와 학습 방안을 도출한다. 예: "확률과 통계에서 접근법몰라 오답이 5건으로 가장 많음 → 조건부확률 개념 재학습 후 유형별 풀이법 정리 필요", "계산실수가 전체 오답의 40%로 시간대별로 반복됨 → 검산 루틴 필요".

6. **`공식집.md` 갱신.** 파일이 이미 있으면 먼저 읽는다. 새로 반영할 내용(새 문제의 커버리지, 새 오답 인사이트)만 기존 구조에 맞춰 추가/수정하고, 나머지 기존 서술은 그대로 둔다. 파일이 없으면 아래 구조로 새로 만든다:
   ```
   # {subject} 공식집 및 학습 요약
   _생성/갱신일: {오늘 날짜}_

   ## 1. 단원별 공식집
   ### {단원명}
   - {공식/개념}: 설명 (관련 문제: 항목번호 #3, #7, ...)
   ...

   ## 2. 문제은행 커버리지
   - 총 문제 수 대비 공식 목록에 매핑된 문제 수
   - 매핑 안 된 문제(있다면) 목록과 사유

   ## 3. 오답 인사이트 및 학습 방안
   ### 오답원인별 집계
   - 계산실수: n건
   - 문제오해: n건
   - 접근법몰라: n건
   - 시간부족: n건

   ### 단원별 취약점
   - {단원명}: 오답 n건, 주요 원인 ..., 추천 학습 방안 ...

   ### 종합 추천
   - 우선순위가 높은 학습 액션 3~5개
   ```

7. 결과를 요약 보고한다: 다룬 단원 수, 매핑된 문제 수/전체 문제 수, 오답원인별 분포, 새로 추가한 공식(있다면), 갱신된 파일 경로.
